# 真实录包的因果停车影子评估

```bash
bash scripts/navigation_recorded_shadow \
  --source-cell /冻结单左前端/robot_localization_hz5_filter_on \
  --window 62 180
```

本流程只问“沿录包原轨迹，当时观测会触发哪些停车或复核条件”。不会发出速度命令、改变原轨迹，也不会声称轮椅已停车。原轨迹扫描不能作为虚拟绕行车在另一个位置的感知，因此不能把本结果包装为真实感知闭环避障。

索引、运行配置、点云及里程计CDR均核验来源哈希、时间和坐标。冻结平面模型的twist在child雷达参考，先旋转到配置车轴方向，再减去角速度叉乘安装杆臂，恢复车轴速度；侧向/Z/横滚俯仰速度不满足平面模型时置未知并复核，不能用未来差分或零值补齐。

实际回波按配置地面候选上方0.05–1.6 m、处理量程0.3–8 m生成体素外接圆盘，保留包络内的近回波。Z保留雷达参考，不冒称完整车轴3D坐标；小于处理最小量程的高度候选点单独保留供复核。地面、量程和近场覆盖均非现场验收值，未看到回波不等于空地，单帧也不能证明目标静止。

因果缓冲区有独立的源时间和交付时间：只交付已经收到的最新源观测，迟到旧包不能覆盖新包，过期保留旧观测但禁止作为可用数据，不把断流当清空。此录包的frontend时间主要是arrival reference，未验证为传感采集时间或逐点时序；注入的250 ms/600 ms延迟及85–90 s断流是实验故障，不是实测真实端到端延迟。

影子判据在捕获时车轴坐标中，以同帧候选速度保留“观测年龄＋反应时间”，然后按假设有限减速度刹停，检查弧线扫掠和保守回波体素。旧扫描未作已验证的自运动补偿、障碍速度未知、物理FoV未知、近量程和负障碍覆盖未验收，都需要复核。没有触发也保持未验收状态。

输出仅有 STOP_REQUIRED、REVIEW_REQUIRED、NO_STOP_TRIGGER_UNVALIDATED。包络重叠可能来自自回波、几何模型或实际障碍；不能直接称真实碰撞。正式门控场景将当前未验收定位设为不可信，要求停车。另设显式“假设定位信号可信”的诊断场景，仅用于比较观测因素，不改变项目定位验收状态。

报告在 `reports/navigation_recorded_shadow/*`，保存来源清单、各帧投影统计、速度候选、五个场景的触发原因和示例预测图。完整录包、地图、标定和控制配置保持原件。
