# 导航研发进度看板

看板集中显示已经归档的地图、路径、数值仿真、近回波和定位证据。它是离线结果快照，不读取实时传感器或当前车位，不启动 ROS，不提供车辆控制。可在二楼电脑浏览，现场检查仍集中安排。

## 一页进展总览

先看这一页：验证阶梯走到了哪一级、几个关键数字、每条工作线做完了什么和正在做什么、走廊地图（全图、同一处的新旧对比放大图、质量数字表），以及需要用户做的事。文字来自人工整理的内容文件（JSON，`schema_version` 为 1），由总管在巡检或合并后更新；地图图直接由地图文件和建图轨迹绘制，不经过任何拟合。下面的详细看板保留，用于查看具体运行。

```bash
bash scripts/navigation_progress_overview \
  --content ~/wheelchair_coord/overview/overview_content.json \
  --output-dir reports/navigation_dashboard/<日期>_overview
```

内容文件里每段文字都会转义，阶梯状态只能是 `done`、`doing`、`waiting`、`todo`，字段多了或缺了都会拒绝。输出目录必须是 reports 下的新目录，已有的不覆盖；目录里有 `index.html`（不含脚本，可直接打开）、各张地图图、内容文件副本和 `manifest.json`（内容、页面、地图、轨迹、各张图和各数据来源的 SHA256）。

地图图写在内容文件的 `figures` 里，最多 6 张。每张的字段：

- `title`、`caption`：标题和说明；
- `map_yaml`：map_server 格式的地图；
- `path_csv`：可选，建图轨迹（`used_x`、`used_y` 两列），画成蓝线，起点画绿色实心圆；
- `window`：可选，`[x_min, y_min, x_max, y_max]`，单位米。不给时画整张图看到的部分；给了就正好画这块地方，原点不同的两张图也能并排比较同一处，图外的部分画成未知；
- `markers`：可选，编号标记 `{"x": 米, "y": 米, "label": "1"}`，画成红圈。编号只能是 1–3 个英文字母或数字（画在图里），含义写在说明里。

每张图写两份：页面上的 `figN.png`（宽不超过 1000 像素）和原尺寸的 `figN_full.png`（每格最多 8 像素、最长 4000 像素），点页面上的图打开原尺寸，可以放大看每一格。左下角是比例尺。整张图占满一行，带 `window` 的放大图两张一行，方便新旧对比。

`map_table` 是可选的对比表（`columns`、`rows`、可选的 `note`），放在图下面。原来的单图字段 `map` 仍可用，相当于一张标题为“在用的走廊地图”的整张图。

生成后还会刷新上一级目录（`reports/navigation_dashboard/`）里的 `index.html`：一个入口页，顶上是“打开最新的进展总览”，下面列出以前的总览和旧版详细看板。入口页只是指针，每次整体替换；各快照目录不动。所以浏览时只要记住看板服务的根地址。加 `--no-landing` 可以不刷新入口页。

## 四个页面

- 进度总览：已完成工作、用途、局限、导航测试来源和本轮交叉验证；不使用没有依据的完成百分比。
- 地图与绕行：同一冻结地图下的原路径、四种数值场景和时间回看。侧方绕行实际采用经过连续扫掠复核的栅格 A* 回退，不能标成 Nav2 路线通过；时间轴上未发生的换路不提前显示。
- 近回波核查：六个真实录包时刻的车体 XY、准备后左雷达 Z、圆内原始保留点与保守体素外扩，分别显示。假定半径与地面不是实测值，不产生自回波屏蔽。
- 定位可信度：两种模型各 132 帧的共享先验分歧、粒子标准差、覆盖与歧义分类。全部帧仍未可信，里程计不冒充独立物理真值；纳秒源时间以字符串保留，避免浏览器数值精度丢失。

## 生成新快照

```bash
bash scripts/navigation_dashboard \
  --snapshot /配置数据根/reports/本次快照/snapshot.json \
  --output reports/navigation_dashboard/本次快照/index.html
```

渲染器只接受明确标记 `OFFLINE_SNAPSHOT`、非实时、物理导航未验收的有界 JSON。输出经 StoragePolicy 放在配置 reports 内；已有快照不覆盖。报告文字在嵌入时进行转义，不能关闭 JSON 脚本标签注入页面。页面不加载外部脚本、字体或网络数据。

生成的 `index.html` 包含所需地图图像与显示数据，可以直接在浏览器打开，也可通过只绑定本机回环地址的静态服务查看。后续实验完成后重新生成一个新快照；页面显示生成时间，不把旧快照显示为实时进度。数据生成应校验输入报告、地图、路径的 SHA256，并保留来源清单。

本轮补充覆盖实验：在同一录包分离时间段上使用相同 37 帧、相同一次性初始位姿，分别重放旧训练地图和增加至 372 帧的训练地图。已知覆盖率约从 18.65% 增加到 21.63%，37 帧仍全部覆盖/支持不足，共享先验冲突未改善。扩展地图未用于导航。已有独立录包候选仍需重新准备单左雷达输入，不能把同源的多组结果当成独立验证。
