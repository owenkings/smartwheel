# 智能轮椅工作面板

本页说明七个功能的操作方式。软件在 Orin 本地桌面运行，主窗口只保留功能按钮；在线和录制使用统一 RViz 窗口。

主窗口采用三行布局：第一行居中为“实时建图”（包含实时预览）；第二行为“数据录制、离线融合、结果对比”；第三行为“设备参数、数据与存储、日志”。

## 启动

在 Orin 图形桌面的终端中，从任意当前目录执行：

```bash
bash /home/nvidia/wheelchair/scripts/panel
```

入口是 Bash 脚本。普通 SSH 会话通常没有图形显示环境；实际使用请在 Orin 本机桌面或已有远程桌面中启动。Windows 源码备份不能直接代替目标平台运行。只查看帮助可执行 `bash /home/nvidia/wheelchair/scripts/panel --help`。

当前 Orin 使用 colcon 隔离安装；工程内安装入口也可从任意目录执行：

```bash
/home/nvidia/wheelchair/install/main/wc_bringup/lib/wc_bringup/panel
```

入口按自身位置寻找工程，不依赖当前目录；符号链接会解析到实际脚本。若脚本被复制到工程以外，需要显式设置 `WHEELCHAIR_PROJECT_ROOT`。界面依赖项目当前 Python、PyQt5、NumPy，以及已有 ROS/RViz 程序；三维结果浏览不需要联网或浏览器插件。安装位置与执行权限由部署步骤设置。

同一用户只允许一个主面板实例。实时、录制或恢复任务运行时关闭主面板会使其最小化，任务仍由面板监督；先从对应窗口正常结束任务，再退出主面板。仅有离线队列运行时可退出主面板，独立后台进程继续执行；重新打开面板可查看原队列。关闭离线融合副窗口不会取消队列。

## 实时融合

1. 点击主面板“实时建图”，在实时融合副窗口选择预览或实时建图、左/右/双雷达、raw/filtered、官方/五状态 EKF。
2. 按需选择运动修正、过程噪声和几何方案。选项旁显示实际生效条件；不可用选项保留并置灰。
3. 点击“确认并打开 RViz”。参数窗口关闭，随后由任务打开统一 RViz，不另建常驻进度窗口。
4. 选择实时建图时，窗口初始只显示当前帧；点击“开始建图”创建一份新地图。按钮变为“停止并保存”，建图期间显示本次累计三维云及二维地图。
5. 点击“停止并保存”，等待本次数据库及录包正常关闭；窗口恢复当前帧实时预览，再打开旧地图保存选择。保存期间窗口保留真实预览，按钮暂不可用；保存、取消或待处理结果返回后可以再次开始新地图。

首次打开时使用当前项目的 EKF 默认值，配置未显式指定时为五状态；同一面板会话中保留用户的选择。启动前按所选雷达核实外参和算法条件，缺少实测外参时只阻止依赖该外参的建图，原生预览仍可使用。 缺少跨雷达实测外参时，双雷达预览顶部提供“原生坐标”左右切换，分别查看各自点云；不生成猜测的变换，也不表示两侧已对齐。

预览只展示实时数据。建图窗口中间显示实时三维点云和累计三维点云；左栏为左前、左侧相机及 2D 栅格地图，右栏为右前、右侧相机及参数/状态。三维视角可旋转、平移、缩放。

官方 EKF 的几何反馈始终置灰并说明“尚未实现”。连续白加速度 PSD 当前仅用于五状态 EKF 实时建图。五状态几何纠偏修正发布位姿，不应解释为已经向官方 EKF 回灌几何观测。

在线运动修正必须有匹配当前设备身份的有效设备校正声明和零偏证据。“在线校正设置…”会定位到设备参数中的在线校正组；选择声明、零偏确认和声明证据文件后，先读取校验，再保存。实际核验四个文件：设备声明及其证据、零偏确认及其同名 `.evidence.json`。没有有效声明时保持禁用；录制会话的离线修正候选不会被自动套用到实时任务。

每次开始使用新的会话目录及数据库，上一张地图不会叠入下一张。预览与建图切换期间会短暂关闭并重新打开所属设备，界面显示“正在切换”，旧点云、地图及按键状态被清空。切换中的“取消开始”会等待当前步骤安全收尾后恢复预览。

点击“停止并保存”后才询问旧地图是否保存及最终路径。取消路径选择返回保存选择流程；取消整个保存选择或保存失败会保留临时结果。选择不保存只清理这份已经停止的地图及其临时原始记录，不影响新预览或独立录制。直接关闭整个 RViz 窗口会停止所属设备，取消尚未完成的保存进程并保留未完成地图，随后可从恢复入口处理；不会在窗口关闭后继续无人管理的采集或导出。纯预览结束不弹出地图保存选择。

启动主面板时会检查保留的临时地图。在“实时建图 → 恢复未完成地图”中选择会话，重新打开保存选择。只有已确认正常停止、关闭数据库的会话可恢复处理；异常残留缺少关闭证据时显示具体阻塞原因，不强行导出。取消保存弹窗后，任务显示“待保存处理”，不会标记为保存成功。

副面板下拉列表采用圆角浮层，当前选项带勾选标记；按可用空间向上或向下展开，避让底部操作按钮。点击或回车确认选项，Esc 或点击外部收起并保持原值。选项多时在列表内滚动。未展开的下拉框、数字输入框及其编辑区不响应滚轮改值，滚轮用于滚动所在页面。滚动条仅在内容溢出时出现，鼠标移入或拖动时加深加宽。

## 数据录制

常规数据录制会启用人工驾驶通道，使用前确认设备与现场条件。静态标定采集可从“设备参数 → 打开点云配对工具 → 录制新数据／从录包准备点云”进入，该入口关闭人工驾驶通道。

数据名称与雷达选择同一行：左侧填写前缀，右侧选择双雷达／单雷达；可勾选年份 `YYYY`、日期 `MMDD`、时间 `HHMMSS`，以 `_` 连接，例如 `走廊往返_2026_1008_153020`。下方显示预览，以实际启动时刻为准。同名目录自动追加 `_02` 等序号，不覆盖原数据；中文名称与内部 ASCII 会话编号分离，录包校验和离线运动修正仍校验内部身份。

选择保存根目录和左/右/双雷达，点击确认。每次录制在根目录下自动建立带日期、时间和防重名后缀的独立子文件夹。

统一录制 RViz 的左栏上半部显示左雷达信息、下半部显示右雷达信息；中、右两栏分别显示左右点云。单雷达模式明确标记未使用的一侧。结束时点击窗口顶部“结束录制”或正常关闭窗口，等待数据收尾和完整性检查。主面板会显示实际收尾阶段及最终目录，通过完整性检查后弹出“录制已完成”；失败则显示原因和数据目录，并明确数据可能不完整。窗口关闭本身不代表数据已完整落盘。

本次选择的路径只影响本次录制，不自动改变全局默认路径。

## 离线融合

选定录制后，在“使用录制中的雷达”选择双雷达、仅左雷达或仅右雷达。选项依据录包内实际点云消息启用；所选雷达缺少的 raw / filtered 方案会置灰。此选择贯穿运动候选、回放及地图输出，结果标注雷达来源，原录包不变。单侧结果用于离线对照，不能据此宣称已完成单雷达实机建图验收。

录制根目录默认沿用“数据与存储”的设置，也可临时另选。窗口自动识别有效录制子文件夹，下拉选择一组数据，再选择融合结果路径和对照方案。选择框下方显示完整名称并自动换行；底部的已有批次、查看队列和开始操作固定显示。上方参数与完整方案表共用一处纵向滚动，鼠标停在表格或说明文字上也可继续滚动；滚到方案表内时列标题固定可见；用方向键选中方案时，页面自动显示该行。

方案表显示 EKF、点云来源、点云筛选、过程噪声、修正和生效条件。“全选有效方案”只选已接通的组合；官方几何反馈保留灰色行。确认前会显示实际任务列表及输出路径。运动修正方案先运行该录制自身的候选计算和校验阶段，同一雷达选择和同一 raw / filtered 类型下，两个 EKF 使用相同的有效候选；混合点云类型的批次分别生成时钟绑定候选。

算法开关使用本次选择；外参、轮参数和基础算法数值使用该录制的冻结配置。修改当前设备参数不会改写历史录制，也不会改变已排队任务的来源配置。

“使用机械初值（离线实验）”和“允许处理未完整结束的录制（诊断）”均默认关闭，只有明确需要时才选择。前者不修改实时外参，后者不把不完整数据变成完整录制。

启动后同一副窗口切换为队列、进度和日志。首版队列管理当前一个录包的一批参数组合；当前批次结束后才可新建任务，不提供多录包批次追加管理。关闭后重新打开，未结束批次自动恢复显示；已结束批次可从方案窗口底部选择已有批次，再点击“查看已有队列”读取实际阶段、终态、结果位置和失败原因，不会重新执行融合。进度按实际完成阶段计算，不估算未验证的帧进度。点击“取消剩余任务”会停止当前离线计算并取消后续任务，等待取消收尾完成；已产生的结果保留。

## 结果对比

查看窗口采用圆角卡片和分段切换按钮。2D 地图及图片路线支持鼠标指向处滚轮缩放、左键拖动平移、双击复位，也可点击“− / + / 适应窗口”。比例显示当前图像的缩放倍率。手动放大后调整窗口大小会保留视图；鼠标在地图和三维画布上时，滚轮作用于画布，在卡片空白处时滚动结果列表。

选择融合结果根目录，再选择一组或多组结果。按住 Ctrl/Shift 可多选，点击“打开所选结果”。

每张结果卡片包含 2D 地图、路线、3D 点云三个页签，可统一切换或分别查看。三维操作：左键拖动旋转，右键/中键拖动平移，滚轮缩放，双击或“复位视角”恢复初始视角。“联动三维视角”同步这些操作，不表示不同结果已完成空间配准。没有时间轴。

路线默认优先读取 CSV 坐标，并对所有已选结果使用相同米制比例和 XY 视域；可取消“路线统一米制比例”独立查看。只有图片而没有米制坐标的路线会明确提示无法保证同尺度，不把图片缩放当作米制对齐。

大点云从真实导出文件确定性抽样，界面显示原始点数和显示点数；不会改写原文件。支持 PLY、PLY.XZ、ASCII/binary/binary_compressed PCD 及其 PCD.XZ 归档。压缩文件采用流式读取，不生成解压副本；XZ 解码器内存上限为 128 MiB，解码数据总量上限为 4 GiB。合法拼接 XZ 流与 padding 可读取，损坏内容或垃圾尾部会拒绝。读取同时检查声明点数和数据长度。显示最多约 18 万采样点，放大视角不会恢复未显示的细节点。没有图片、路线或点云的结果会显示缺失说明，不以示意内容替代实际数据。

## 设备参数

默认进入设备概览，显示安装基准相对轮轴的位置、IMU 朝向、雷达原点间距、轮半径和轮中心距。未确定的数据原点关系保持未知，机械外壳或 CAD 表面尺寸不当作雷达原点位置。已知 IMU 朝向与未知 IMU 位置分别显示；当前轮尺寸同时标注核验状态。“修改轮尺寸”只编辑两个常用尺寸（毫米），保留其他轮参数；仍需确认影响、版本校验和备份。矩阵、测量依据和算法参数可通过高级入口查看或编辑。

当前设备配置和录包冻结配置用途不同：设备概览不会把离线机械初值冒充已标定数据外参。历史结果实际采用的转换，以对应的 `runtime_config.json` / `frozen_runtime_config.json` 为准。

“选择／保存配置集”列出当前文件路径，可将当前支持参数另存为命名配置集，并预览、确认切换。支持编辑的三个文件为 `hardware_setup.json`（安装关系和轮参数）、`mapping_live.json`（算法默认值）、`cameras.json`（相机及显示）。当前机器优先读写 `config/local/project/` 下的完整私有副本，缺少副本时使用 `config/` 基础文件；页面显示实际路径。首次使用前按[部署步骤](../../README.md#5-配置本机设备保留公开模板)创建私有副本。命名配置集位于忽略的 `config/panel_profiles/`，与本机配置一起私下备份。切换时保留设备身份与装配绑定，核对测量依据、备份原文件并支持失败恢复。新档案记录实际配置路径；来源路径改变、档案损坏或不支持的旧格式会拒绝恢复并保留原件，不能通过改哈希绕过。请等待实时／录制任务停止和收尾后再切换；已有录包的冻结参数不受影响。

“打开点云配对工具”复用已有离线选点及拖动 / ICP 功能，选择准备好的 `prepared.json` 后启动本机网页。默认清单可能是历史场景，启动前请核对输入；可显式选择幅度图联动选点准备的文件。结果分别保存到当前数据存储的 `data/calibration/manual_points` 或 `data/calibration/alignment_candidates`，不会自动覆盖正式外参。窗口显示本次工具状态、日志和结果目录；关闭会停止本次服务，已导出的候选保留，不影响其他已运行的工具。

配对录制同样提供名称前缀和年份 `YYYY`、日期 `MMDD`、时间 `HHMMSS` 三个后缀勾选项，默认全选，以 `_` 连接。名称预览随本地时间更新；启动后显示实际保存文件夹名，录制与收尾期间锁定命名选项。同名追加序号，空名称或非法路径字符会阻止启动。这里命名的是原始录制文件夹，后续准备文件仍为独立目录中的 `prepared.json`。

配对窗口增加“录制新数据／从录包准备点云”：在静止且双雷达视野重叠的场景中录制，停止后等待原录包 COMPLETE 和完整性检查，再生成独立的 `prepared.json`；也可选择已完成双雷达录包。此入口关闭手动驾驶链路，但保留现有录制的来源就绪与完整性要求。准备时核对原始帧身份、哈希与同一会话，保留原始录包；主机到达时间接近不宣称曝光同步。只有录包确实保留像素顺序和幅度信息时才提供幅度图，否则明确仅提供真实 XYZ 点云。短静态录制建议约 10～20 秒，现场静止和独立标定验证仍由用户确认。

设备身份只读。外参、轮参数、显示设置、算法配置默认只读；点击“编辑此组参数”时先显示警告。取消警告不会解锁编辑或写入配置。

“安装参数与 IMU”按设备显示前后／左右／上下位置（毫米）及横滚／俯仰／偏航（度），每项写明参考坐标系和方向。修改完整的位置与朝向会自动计算右雷达→左雷达、雷达→轮轴及 IMU→轮轴的变换预览；只填高度或间距不足以唯一确定完整外参。未知位置不阻止显示已知朝向。原有高级页仍以米和 3×3 旋转矩阵提供完整外参；身份、坐标系方向和单位不可随意重绑定。未知平移/旋转保持空值；显式输入时必须填完整有限数值，并通过原有外参校验。不会自动将未知值填成零或单位矩阵。

外参编辑时可点击“导入并绑定测量证据…”，明确选择目标外参、平移或旋转分量、原始证据文件、证据类型及绑定方式，并确认当前装配版本。此时只校验证据并绑定来源；数值和依据等级仍保持原值，文件和配置尚未写入。依据等级通过下拉框单独选择，选择“未知”不能配上非空数值后视为有效。点击主参数窗口“保存参数”才会再次核对来源哈希、复制证据原文并保存配置。取消编辑不保存本次绑定。文件证据通过校验不等于物理精度得到验证。

保存会校验参数和读入版本，备份原配置。外参、轮参数、算法和配置型显示设置对下一次任务生效；当前任务保留启动时配置。结果查看窗口的视角调整立即生效。在线设备校正从有证据的文件导入，校验通过后仍需点击“保存参数”才写入运行配置。

在线校正组顶部明确显示“未配置”“尚未验证”或“已通过验证、尚未保存”；下方模板中的声明类型不代表校正已生效。

## 数据与存储

这里管理录制和融合结果两个全局默认根目录。选择已存在且相互独立的目录并保存；新的功能窗口默认读取这些路径。已打开窗口若仍使用旧默认值，也会同步更新；手动选过的临时路径保留。

下方按根目录显示文件大小、实际分配占用及目录项，包括根目录散文件和隐藏项；两种大小在 exFAT 等文件系统上可能差异明显。不可读、链接、嵌套挂载或无法确认占用状态的项会显示原因，未知大小不会显示为零。统计不完整时只显示已知部分，并明确提示不能作为全部占用。

仅允许选择完整可读、非隐藏且未运行的直接子目录清理。软件先列出具体路径和两种大小，再询问是否永久删除。取消不会删除。清理结束显示磁盘可用空间的实测变化，该变化可能受到其他任务同时写入的影响。更改默认路径不搬迁已有数据。

## 日志

按任务选择录制、实时或离线日志，再用“日志来源”切换任务总日志和实际阶段日志。首次打开即读取正文，总日志为空时优先展示有内容的阶段日志；空文件和不可读取状态会明确说明。任务时间按本地时区显示日期时间及 UTC 偏移。可以关闭自动滚动并打开所选日志所在目录。任务错误以实际日志为准。设备未连接、外参未知或存储不可用时应显示原因，不会自动改用另一算法或悄悄写入其他磁盘。

### 只做软件验收的命令

以下命令不启动传感器或执行融合任务。输出路径应选择配置数据根目录中的报告目录。

```bash
PYTHONPATH=/home/nvidia/wheelchair/src QT_QPA_PLATFORM=offscreen \
  python3 -m unittest discover -s /home/nvidia/wheelchair/tests/panel_ui -p test_panel_ui.py -v

PYTHONPATH=/home/nvidia/wheelchair/src QT_QPA_PLATFORM=offscreen \
  python3 /home/nvidia/wheelchair/tests/panel_ui/render_screenshots.py \
  --project-root /home/nvidia/wheelchair --output /明确选择的报告目录 \
  --result-groups 02 04 12 --job-id 20261008_012911_feb03635
```

截图脚本不带 `--fixture` 时读取当前配置和真实文件；`--fixture` 仅生成明确标记的合成界面测试内容。`--with-results` 默认选择前两组有点云的结果；`--result-groups 02 04 12` 按组号精确选择，缺失或重名会报错，可用 `--results-root` 指定批次所在根目录。脚本截图 2D、路线和可交互 3D，并为所选每组单独截图，避免第三组位于滚动区下方而没有留下可见证据。清单记录源码 SHA256、实际文件路径和点云读取状态；读取失败返回非零状态。只读取结果，不重跑融合。原生 RViz、保存选择和真实设备画面由单独目标机验收记录。

`--job-id` 必须对应已经存在的离线任务；示例 ID 来自既有验收任务，可按实际历史记录替换。脚本通过“查看已有队列”这一实际界面入口重新打开批次，保留真实终态，再截图该任务的非空阶段日志。清单记录任务来源、阶段状态、日志路径及正文哈希；不会创建融合任务或将已完成状态伪装为运行中。
