# 持续阻挡后的重规划数值验证

```bash
bash scripts/navigation_replan_sim \
  --plan-result /配置数据根/reports/navigation/成功冻结结果/result.json
```

使用原保护地图、原假设圆形包络及原全局目标。演示沿冻结路径指定偏侧直径0.30 m的圆盘、居中直径0.60 m圆盘，以及观测/定位失信场景。障碍均为合成夹具，现有地图来源与占据格不修改；未知和地图外仍不可通行。其他地图不保证同一夹具可绕行，必须检查报告。

控制器先按既有有限制动模型停稳。只有实际运动后、观测新鲜、定位信任信号有效、当前观测表明静态阻挡持续时，才向规划回调提交当前位姿、原目标、观测时间与已观测轨道。不能依据世界事件中的未来消失时刻判定“永久”。

回调将观测中心按已知恒速模型投影到当前请求时刻，对圆盘相交的原自由单元加占据。原占据、未知及底图保持，独立保存临时地图与来源报告。在localhost域93中只启动map_server和planner_server，使用已有Navfn A*和原包络；另用保守离散A*诊断连通性。离散NO_PATH不是物理绝对无路，Nav2错误也不能包装成地图无路。

Nav2路径的格中心端点用连续扫掠验证的连接段接到当前停稳点和原目标。控制器保持停稳并模拟0.5 s规划交付延迟；实际Nav2墙钟耗时另行记录，0.5 s是假设而非实测延迟。交付时重新检查定位、观测、起终点、底图扫掠与最新障碍，才安装路径。安装只重置路径进度，不重置全局时间、位姿、速度、传感或世界状态。

相同阻挡几何的NO_PATH只尝试一次，错误/几何变化按冷却和总次数上限处理。无路、不可信或校验失败均继续有限制动/停等，不缩包络、不清未知、不跳过碰撞步，也不向车辆发布命令。

默认运行四个场景：偏侧障碍绕行、居中封堵无路、定位失信、观测断流。每项保存世界夹具、规划请求及临时地图、Nav2日志、路径安装时刻、完整连续轨迹和独立扫掠审计。结果进入 `reports/navigation_replanning/*`；底图仍在其原路径。

全部结果基于虚拟定位、理想延迟圆盘观测、准确恒速轨道和假设制动参数。沿程定位歧义、真实障碍检测、执行反馈和实车验收仍需补齐。用户二楼、轮椅四楼的约束继续保留；不可避免的包络、制动及补录现场事项按集中清单准备。

返回[停车仿真](navigation_dynamic.md)、[源码](../../src/wc_navigation/README.md)、[测试](../../tests/navigation/README.md)。

规划场景另显式预留0.15 m提前制动净距，覆盖栅格化和规划起点的数值保守性；它只影响与当前剩余路径相交的静态轨道预测，不改变实际障碍、观测快照、地图覆盖圆盘、扫掠审计或原0.55+0.10 m包络。绕行路径不再相交后该额外预测净距撤销。每次Nav2请求在独立进程中运行并销毁DDS参与者，保留域占用检查，避免同一进程连续Context残留发现信息被误作外部节点。

若Nav2确实返回路线但独立连续扫掠校验拒绝，可显式采用同一临时地图、同一包络下已逐段认证的保守8邻域A*路线。报告保留原Nav2路径及拒绝段，selected_planner明确标注回退来源；不能称该路径为Nav2认证成功。Nav2不可用、域冲突或其他环境错误不自动回退。回退不修改任何地图、包络或认证阈值。
