# 冻结路径上的动态停车数值验证

本流程验证虚拟位姿与假设动力学下的路径跟踪、减速停车、持续清空后恢复。当前策略是沿原路径停止等待，不生成绕行路线。运行不需要 ROS，不启动传感器、串口、CAN 或速度发布器。

```bash
bash scripts/navigation_dynamic_sim \
  --plan-result /配置数据根/reports/navigation/成功结果/result.json
```

默认执行全部预声明场景，也可用 `--scenario` 指定 `clear`、`persistent_block`、`temporary_block`、`crossing`、`perception_dropout`、`localization_dropout` 或 `sudden_close_obstacle`。使用先前成功的 Nav2 路径、地图与假设圆形包络，核验地图来源哈希，未知和地图外仍作为静态障碍，不缩小包络。

场景文件记录合成世界中的圆盘位置、恒定速度、半径、出现和消失时间。只有世界审计和传感器适配器使用完整时间表；控制决策只能获得截至当前的延迟观测。定位可信状态也是合成输入，未将当前仍需复核的 AMCL 轨迹接入控制。

模型明确记录最大线/角速度、线/角加速度、采样周期、感知延迟、反应延迟、观测过期时限、持续清空时长及停稳后预测时域。这些是假设值，不能作为真实轮椅的制动性能或传感器时延。理想圆盘观测及恒速预测不能代替真实障碍检测、遮挡、速度估计和执行反馈。

遇障应保持有限减速度积分，停车后继续审计世界时域。独立扫掠审计将机器人和障碍在同一时间上的运动相比较，步内出现/消失按事件时间分段。已证实接触、保守无法认证、等待上限和到达分别记录；不能跳过碰撞步或把瞬时冻结当成安全停车。

突然近距离出现障碍的场景可能物理上来不及停车，必须保留相应失败。程序总状态 `SCENARIOS_EXECUTED_REQUIRES_REVIEW` 只表示预声明场景运行完成；它不是“所有场景安全”，也不代表真实动态避障验收。

报告进入配置数据根的 `reports/navigation_dynamic/*`，保存每个场景的世界配置、时间轨迹、速度、事件和审计结果，以及预览图和总报告。软件测试使用小型合成场景；真实录包地图只用作冻结静态环境。

返回[离线导航](navigation_offline.md)、[源模块](../../src/wc_navigation/README.md)、[测试](../../tests/navigation/README.md)。用户在二楼、轮椅在四楼，先完成本流程；实测包络、急停/制动、低障碍与监督低速验证按集中现场清单安排。

恢复判定另做沿路径的有限加速探测，默认至少前进0.3 m（最多10 s），随后加反应保留、完整刹停与停稳保护时域。无法取得这段可用行程则继续等候，防止固定障碍前反复毫米级起步。clear_stable_s仍必须连续满足。首次传感就绪等待不计为运动中的stop/resume，单独记录hold_release_count。

持续阻挡后的当前观测覆盖与 Nav2 重规划流程见[重规划仿真](navigation_replanning.md)。默认原停车模型不传回调时继续保持原行为。

真实录包输入的[影子停车评估](navigation_recorded_shadow.md)独立于虚拟绕行仿真，禁止把原轨迹扫描当成绕行后的反事实感知。
