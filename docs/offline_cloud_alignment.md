# 手动移动点云与离线 ICP

在 Orin 桌面终端运行：

```bash
cd /home/nvidia/wheelchair
bash scripts/align_lidar_clouds.sh
```

默认打开浏览器 `http://127.0.0.1:8767/alignment`，读取最近录制准备好的固定左右点云，以及属于同一份点云的选点初值和最近保存的配准候选。服务默认运行一小时，终端 `Ctrl+C` 停止。可用 `--duration 7200` 指定时长、`--port 8768` 避开已占用端口。此命令不需要启动 RViz、雷达或轮椅运动。

1. 左云是固定参考，右云是被调整对象。先查看“初始”与“最近 ICP”结果，使用正视、俯视、侧视判断结构；两种颜色在一个屏幕位置混合不代表三维重合。
2. “仅调整视角”模式下拖动只改变观察角度。“拖动右云”模式下拖动改变右云在当前视图平面内的位置。配合三个视图和六个数值输入调整平移与旋转。
3. 平移单位为米；旋转为角度，矩阵顺序 `Rz(yaw) Ry(pitch) Rx(roll)`。变换方向始终是右雷达坐标到左雷达坐标。先让双方共同可见的柜子面、盒子面和地面大体相合，不强行让遮挡或缺失部分对应。
4. 点击 ICP 按钮，从当前摆放位置进行有距离门限、法线和异常对应剔除的点到面配准。结果及最近邻点对另存为新版本，可以回到初始摆放再次比较。请求失败时保留当前调整。
5. “保存手动候选”只保存当前摆放。每次结果保存在 `data/calibration/alignment_candidates/<时间_唯一编号>/`；`result.json` 有变换和指标，`correspondences.json` 有自动匹配的原始点编号，`manifest.json` 有来源及文件校验。原始选点和原始采集数据保留。

最近邻距离只描述算法匹配到的附近点之间的距离，不是外参真实精度；覆盖率、几何退化和视野缺失必须一起看。ICP 是局部优化，初值不合适、共同结构主要是单个平面或左右观测不一致时，可能失败，也可能得到看起来很近但错误的解。

这些结果一律是离线候选，不发布 TF、不覆盖正式外参，不标定雷达内参。正式双雷达建图外参仍需其他场景的独立复核。这一工具也不把顺序录制变为曝光同步；使用当前 `mybox01` 顺序帧的前提是用户确认整个录制期间轮椅、安装件和目标都没有移动。
