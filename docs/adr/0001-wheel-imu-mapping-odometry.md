# ADR 0001：建图默认采用轮速＋IMU里程计

日期：2026-09-14。状态：已实现并通过目标软件回归与真实录包原生重建；新实车动态精度仍未验收。

本决策按用户的新要求，更新 `docs/decisions_001.md` 中早期“不读取或复用旧工程”及默认ICP前端的约定；该旧文件作为当时阶段记录保留。

## 原因

用户要求参考旧版已能行驶和录制点云的实现。旧主入口 `scripts/run_old_rtab_mapping.sh` 实际通过 `manual_mapping_left.launch.py` 指定 `odom_mode=external`、`odom_topic=/odometry/validated`：轮反馈与校正后的 H30 经 EKF、就绪检查提供连续里程计；该入口不启动 `icp_odometry`。旧数据库也保存了点云和变化的位姿记录，详见本轮旧版审查。

新链此前将轮速＋IMU只用作 ICP 初值，连续里程计仍依赖 ICP 成功。现有记录出现过原始雷达观测变化和 ICP 失跟；这些现象尚不能全部归因于硬件。根据用户要求，默认改为直接使用轮速＋IMU位姿，先检验该位姿下的点云累积。

## 决定

- `config/mapping_live.json` 默认 `odometry_source=wheel_imu`。上游轮速＋IMU直接提供 `/wc_mapping/app/odom`，保留原位姿、速度和点云对应的时间戳；SLAM 精确同步 `scan_cloud + odom`。
- wheel_imu 模式只启动原生 `rtabmap_slam/rtabmap`，不启动 ICP 里程计，不订阅或依赖 `OdomInfo`，不采用 ICP 的失跟/配准比例门限判断轮里程计健康。
- `icp` 保留为显式对照选项，保留原两节点路径；运行中不自动切换或回退，避免同一地图悄然改变位姿来源。
- wheel_imu 基线关闭邻接边精修、时间/空间近邻与回环修正，显式 `RGBD/ProximityPathMaxNeighbors=0` 避免原生启动自动设置该项；`RGBD/Enabled=true`，保留原生3D点云、2D栅格与数据库正常保存。旧主入口允许空间回环，本轮暂未照搬这一项。
- TF、话题继续限定在本应用范围。`mapping_odom` 与 `prior_odom` 在该模式下定义为重合的里程计坐标系，不代表补出了任何未知硬件外参。
- 协方差字段使用会话中显式记录的 `UNVALIDATED_MODEL_WEIGHTS`。旧诊断用 `1e6` 会落入原生 RTAB-Map 的里程计重置判定范围，不能直接作为权威里程计输入；新数值是未经标定的模型权重，不是测得的精度或置信区间。

## 影响与边界

轮半径、轮距、反馈比例与方向仍有历史候选属性；轮滑、比例误差和陀螺长期漂移会累积，关闭回环后没有地图回环替它们纠正。该变更不宣称导航精度、绝对定位或当前雷达几何问题已解决。

静止且估计位姿未超过关键帧门限时，累计地图不因重复观测持续增加关键帧；粉色实时点云仍按新帧更新。判断图像是否更新时应区分当前帧与累计地图。

WASD 的寄存器协议、比例和初始化流程已参考旧版。旧面板全局捕获按键且缺失失焦清键，不予继承；新版保留焦点、松键、断连和有界意图处理。用户既有操作经历保留，但 USB/RS485 物理断线停车及固件看门狗行为仍未知，当前真实激活保持禁用，不重复索取已回答的信息。

设备独占、输入新鲜度、运行磁盘保护、失败锁存、只读默认控制以及正常保存检查继续生效；取消 ICP 依赖不等于忽略其他失败。

## 验证与依据

- 实现：`src/wc_runtime/mapping_odometry.py`、`mapping_prior.py`、`mapping_controller.py`、`mapping_monitor.py`；启动配置 `src/wc_bringup/launch/mapping_app.launch.py`。
- 旧版入口及数据库证据：`reports/map_wheel_authority_20260914/old_wasd_review_zh.md`。
- 显式 ICP 生成配置与变更前一致。主控目标 Linux 全回归 620 PASS；末次邻近匹配参数显式置零后，小范围回归 143 PASS、构建和三模式配置通过，两个范围不相加。
- 两次真实录包重建均将 191 对原时间戳 scan/prior 转为权威里程计，原生 3D/2D 各输出 14 次，正常关闭并导出 63762 点 PLY 与二维地图。01/02 地图及位姿文件逐份哈希一致，原始 bag 前后哈希不变；没有启动硬件或控制，也没有重新积分原始 IMU/轮反馈。
- 主控目视确认真实原生地图可见并累计，但仍有重影与多层；不将软件、显示和导出通过解释为几何准确或实车动态验收。完整结果与边界见本轮报告（历史资料见开发归档索引）。
