# 双 XT-M60 环境平面离线标定

> 2026-10-26 起暂停，改用[现场双雷达外参与轮速标定](operations/field_extrinsics.md)。本文保留为过程记录，工具仍可运行。

这是新增离线工具，使用完整录包中的两面墙和地面估计右雷达到左雷达的相对外参。无需逐点手工对应，也不假设墙面互相垂直。点云单位必须为米，轴约定为已核实的 SDK FLU。

变换定义为 `p_left = R @ p_right + t`。这里 `t` 是右点云原点在左坐标系中的坐标，其模长是两点云原点的相对距离。本方法不直接确定原点在外壳内部的位置，也不确定左雷达相对轮轴的位置。

## 处理步骤

1. 复用 `plane_capture.load_capture`，只读解码已关闭、10–60 秒、来源哈希可复核的 COMPLETE 录包。每侧160×60，最后半段最多20组到达时间配对；沿原始像素射线取测距中位数。
2. 过滤无效/超量程点，检测测距跳变边缘，按原始像素连通区域做 RANSAC、内部腐蚀及 TLS 拟合。v2 的贪心消耗只用于生成候选模型；随后回到完整原始有效像素恢复支持，去除重复候选并按最小残差互斥分配，失败候选释放点后有限次重分配。保留全部被剔除点和邻域残差；只有另一块独立合格、方向不同的平面才能解释墙角邻面，不隐藏未知异常。
3. 使用固定内部像素逐帧复核法向、平面距离及覆盖范围。重复帧不充当独立验证；到达时间配对不证明曝光同步。
4. 在明确的机械初值搜索范围内枚举三面种子，进行一对一匹配和 SO(3) 鲁棒联合优化。每份录制等权；法向必须提供三个充分独立方向。拒绝退化、对应歧义和无法完整检查的过大搜索。
5. 固定训练结果后，使用另外录制的 holdout 数据检查；holdout 不参与拟合或训练模型选择。

平面方程为 `n·p+d=0`，单位法向朝向传感器，`d>0`。对应平面满足 `n_left=R@n_right`、`d_right=d_left+n_left·t`。

## 运行

在 Orin 项目中：

```bash
cd /home/nvidia/wheelchair
bash scripts/lidar_environment_calibration \
  --train /media/nvidia/tiany-USB/wheelchair/data/experiments/完整训练录制目录 \
  --holdout /media/nvidia/tiany-USB/wheelchair/data/experiments/另外录制的验证目录
```

可重复传入 `--train` 或 `--holdout`，合计最多8份。只求初步候选时可以省略 holdout。输出目录由当前 `wc_runtime.storage_policy` 决定，包含 JSON、可离线打开的 HTML 分割/三视图报告及完成回执，禁止覆盖旧结果或存储丢失后回退。脚本不启动硬件，不安装 TF，不修改正式外参。

本次默认搜索初值为 `R=I, t=[0,-0.4575,0]m`，只是外壳测量给出的近似初值，不是真实点云原点基线。搜索门限、拟合残差和逐帧稳定性门限均为实验起点，不是标定精度证书。软件仍不估计置信区间。

## 判定与现场摆放

- `REJECTED`：约束、平面质量、对应唯一性或独立验证不合格，不输出可采用的标定结论。
- `CANDIDATE`：仅有训练候选，或缺少独立验证/完整时间检查。合成数据最高为此状态。
- `OFFLINE_VALIDATED_CANDIDATE`：真实独立录制通过几何及时间一致性检查，仍是离线候选；不能据此宣称绝对精度或直接运行。

各状态始终 `live_eligible=false`。不能把平面内点 P95 或重复性数值当作原点定位精度。后续仍需不同位置/朝向的独立录制复现，以及符合目标精度的外部几何真值检查。

现场保持雷达安装不变，让两台雷达同时看见宽阔墙面与地面；尽量远离墙角，给下视范围留出足够地面。若地面太窄，三块竖直墙面也不能替代高度方向约束。只由现场操作者调整轮椅，开始录制前确认就绪，收到结束提示后再移动。

## 后续现场方法

先使用确实平整、不反光的大硬板或已检查的平墙，分别检查两台雷达的内部区域、未筛选邻域和固定像素逐帧观测。曲面局部可能被RANSAC拟合成低残差小面片，程序不能仅凭小片内点残差证明整墙平直。当前数据不足以把异常归因于曲率、反射、混合像素、测距/角度处理或其他具体原因；先用已知平面把现场几何和传感器观测分开验证。

单台观测检查通过后，保持雷达安装不变，让同一块大平板在两台共同视野内保持静止，以多种倾角分别录制；训练数据的法向整体应张成三维，不必依赖狭窄地面。每个姿态中的对应平面在两台雷达间匹配，不跨姿态假装是同一固定世界平面。验证组另行录制，法向也应整体充分独立；当前入口合计最多8份训练与验证录制。再联合求相对外参并检查独立验证。即使离线一致，若要宣称特定毫米级精度，仍需相应精度的外部真值。

文献依据：[A Novel Dual-Lidar Calibration Algorithm Using Planar Surfaces](https://arxiv.org/abs/1904.12116) 与 [Extrinsic Calibration of Multiple 3D LiDAR Sensors by the Use of Planar Objects](https://pubmed.ncbi.nlm.nih.gov/36236333/) 使用独立平面方向约束进行自动标定。其可行性和其他设备上的实验结果不构成本项目精度保证。

## 受控50厘米木板：完整板与内部区域两个入口

深层问题是“现有观测是否提供了可靠、独立且可验证的六自由度约束”。重复录制同一方向、手工点更精细，均不能补上缺失的方向。点云外参解决两个SDK坐标系之间的刚体变换；外壳中的物理原点位置和轮轴基准需另有机械参考，不能混为同一个标定任务。

`scripts/lidar_small_board_calibration` 使用同一块板同一面、多份静止录制联合求解。完整板自动分支复用原始像素连通、深度边缘和固定内部区域；每份录制只提供一对平面，不要求同一时刻具备墙墙地三方向。至少正对、左右转斜、上下俯仰三类姿态，使训练组法向整体张成三维；仅绕竖直轴左右转斜不足以可靠约束高度平移。两台雷达安装始终不变，木板每次固定后单独静止录制。具体角度约25–30度只是摆放起点，程序按实际法向条件数判定。

小板质量门限在新增录包前声明：固定内部点至少80个、两个方向5%–95%跨度各至少0.25米、原始像素相邻三角网格投影面积至少0.08平方米、内部TLS RMSE≤20毫米/P95≤40毫米；原始候选相对内部面的P95≤75毫米、超过50毫米的点占比≤20%。不能用凸包面积替代被孔洞/边缘损失后的真实网格面积。逐帧门限完全复用环境模块，不以诊断的 `EVALUATED` 冒充时间PASS，也不按残差重新挑内部点。这些只是试验筛选条件，不是原点精度证书。

若板和支撑在深度图相接，程序不能只把距离带扩大就宣称找到了完整板。此时有独立的“受控板内区域”入口：操作者确认每侧粗矩形完全属于同一木板的同一面；程序在矩形内按原像素腐蚀和深度边缘规则确定固定支持，所有有限内部点参与TLS，不需要标角点或手工指定点对应。它不声称看见板四边，也不声称已证明整板平直。上述面积、跨度、残差和时间门限全部保持；原矩形全点、剔除索引、外一圈及全图相对板面的残差同时保存，箱子/背景残差仅作诊断。未确认选区身份时可以输出诊断，但不能产生合格平面输入。

先获取三份合格训练姿态，再另外录制三份充分独立的验证姿态；验证组不得参与训练拟合或选择。合成解析射线回归覆盖完整有限板、内部选区、不同安装外参、独立验证失败以及仅左右转动的退化情况，合成结果最高标为CANDIDATE，不代表实机精度。实际入口共最多8份录制，所有状态 `live_eligible=false`，不会修改正式外参或TF。
