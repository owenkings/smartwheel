## 尚未满足的现场条件

1. 当前正式配置没有左、右雷达数据原点到轮轴的完整可信实测/标定变换。单雷达建图需该侧，双雷达需两侧。机械尺寸不能替代数据坐标原点，不以猜测解除限制。此时双雷达原生预览按左右各自坐标分别查看，不宣称已跨雷达对齐或融合。
2. 在线运动修正另需匹配设备身份的校正声明、零偏确认及证据。文件哈希不证明物理标定精度；用户须显式确认状态和装配版本。
3. 官方 EKF 几何反馈不支持，在界面置灰。两种 EKF 保留，默认沿用当前配置；本轮没有重新评价或删除算法，也没有重复其他会话 PSD 对照。
4. 静态录制验收排除了驾驶进程；生产入口保留手推/WASD。静态四相机预览使用内存中的测试适配器排除控制进程，没有修改正式配置、绕过建图条件或发送执行器指令。人工移动、现场实时建图和真实地图关闭保存，待条件齐备后由用户操作验收。
