# 源码与本机资料边界

版本库保存维护源码、通用配置、必要来源、测试和当前说明。设备身份、机器覆盖、录包、地图、图像、日志、开发归档与运行状态留在本机或选定数据根。

公开配置中的示例身份不代表已完成设备校验。换机时通过本机覆盖恢复实际绑定和测量依据，再执行相应验证；不能直接使用另一台设备的已验证时间或标定配置。

发布前枚举全部维护文件，确认新增文件没有遗漏，校验配置到证据的引用闭合。使用干净导出验证构建和软件行为，并记录原始源码与公开副本的对应关系。

本地工作完成不代表已经推送。只有远端提交及文件树读回一致，才能记录为发布成功。未经要求不更新其他分支，也不改写已保留的历史。
