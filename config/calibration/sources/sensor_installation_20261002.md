# 传感器安装位置与距离（机械设计标称值）

更新：2026-10-02（左滑盖 v2 的栓槽和后挡前移 0.5）。2026-10-01 横向基准改用支架装好后的 U 型夹板实测，并已用盒间距和雷达窗中心距复核。

本文给出两个 XT-M60 雷达、四个摄像头、H30 IMU 以及盒内四个双孔传感器之间的位置关系，作为后续计算外参的初值和实物核对依据。

> 性质说明：数值来自 CAD 设计模型和人工测量，是设计标称值，不是标定结果。本文的参考点是硬件外形（CAD 包络）的面中心，不等于雷达测量原点、相机光心或 IMU 测量中心。外参最终要经实测和标定确认。数值保留两位小数只为便于核对计算，不代表实际精度。

## 2. 坐标系

### 2.1 安装参考系 M

本文所有坐标都在 M 系中，单位 mm。

- 右手系，按 ROS REP 103 约定：x 向前，y 向左，z 向上。
- 原点：
  - 横向：左右两块铁片中心面的中点。实际按支架夹缝中心面计算，夹缝比铁片宽约 0.2，两者最多差 0.1；
  - 前后：每块铁片上两颗 M6 螺栓孔轴线的中点；
  - 高度：M6 螺栓孔中心。
- 前提（待核查）：左右铁片前后位置一致、高度一致、相互平行。
- M 系到车体坐标（如 base_link 或轮轴中心）的变换没有测量，需要另外实测。

俯视示意（不按比例）：


### 2.2 CAD 模型坐标换算到 M 系

两个盒子的模型坐标轴物理含义相同：+X 指向轮椅左侧，+Y 指向后方，+Z 向上。左盒几何是右盒的镜像，但坐标轴方向没有反。

| 模型 | x_M | y_M | z_M |
|---|---|---|---|
| 右盒 (X, Y, Z) | 50 - Y | X - 379.5 | Z + 13.5 |
| 左盒 (X, Y, Z) | 50 - Y | X + 117.7 | Z + 13.5 |

换算依据（从模型量得）：

- 支架夹缝中心：右盒 X = 133.4，左盒 X = 128.4（夹缝宽 3.2），按第 3.1 节的实测分别对应 y_M = -246.1 和 +246.1。
- M6 长圆孔中心：Y = 42.5 和 57.5（中点 Y = 50.0），Z = -13.5。
- U 型夹板：夹缝两侧各一块，厚 5.0。座椅侧夹板在右盒 X = 135.0 ~ 140.0、左盒 X = 121.8 ~ 126.8；外侧夹板在右盒 X = 126.8 ~ 131.8、左盒 X = 130.0 ~ 135.0。模型对象名里的“内/外”叫法不统一，以 X 范围为准。

## 3. 实测输入与推导

### 3.1 U 型夹板实测（现用）

支架装好后，用卷尺以 U 型夹板为基准测量（不是量铁片）：

- 左右座椅侧夹板朝座椅面之间：479 mm；
- 左右座椅侧夹板贴铁片面之间：489 mm。

推导：

- 自洽：489 - 479 = 10 mm，正好是两块 5.0 mm 夹板（模型值）的厚度。
- 夹缝中心面间距 = 489 + 3.2 = 492.2 mm（也等于 479 + 2 × 5 + 3.2），左、右夹缝中心面在 y = +246.1 和 -246.1。
- 与旧值 490.0 相比，左右盒的横向坐标各向外改 1.1 mm。同一盒内的相对位置不变；左右之间的 Δy 都增加 2.2 mm，例如左右雷达 433.5 → 435.7。
- 精度：卷尺读数约 ±1 mm。尺身没拉直或与夹板不垂直时读数偏大。复核结果见第 3.3 节。

### 3.2 旧测量（铁片，已停用）

- 支架安装前在铁片上量得外侧面间距 494、内侧面间距 486，平均得中心面间距 490.0。494 - 486 = 8 相当于每块铁片厚 4 mm，与 3.2 mm 夹缝矛盾，当时已判断至少有一个数不准。
- 铁片夹在夹缝里，它朝座椅的面不会比夹板贴铁片面更靠里，所以两铁片内侧面间距不小于 489。按 3 mm 铁片，外侧面间距约 495。旧测 494 差约 1 mm，在卷尺误差内；486 差约 3 mm，判为测量误差。
- 如果旧测是在铁片的其他位置量的（如焊接根部），差值也可能来自两块铁片不平行，待核查。第 7 节按前后、上下分别量盒间距可以检查这一点。

### 3.3 装盒后复核

装上盒子后用卷尺测量，与按 492.2 算出的设计值比较：

| 复核项 | 实测 | 设计值（492.2） | 差 | 反推中心面间距 | 按旧值 490.0 应为 |
|---|---:|---:|---:|---:|---:|
| 两盒内侧墙外表面间距 | 394 | 393.2 | +0.8 | 493.0 | 391.0 |
| 左右雷达窗中心距 | 436 | 435.7 | +0.3 | 492.5 | 433.5 |

- 反推方法：模型里夹缝中心到内侧墙外表面的横向距离是 49.5，到雷达窗中心是 28.25，所以 394 + 2 × 49.5 = 493.0，436 + 2 × 28.25 = 492.5。
- 两项都只比设计值略大，在卷尺误差内。按旧值 490.0 会差 3.0 和 2.5，旧值被否定。
- 三组测量反推的中心面间距为 492.2、493.0、492.5，相差 0.8，在卷尺精度内。本文保持 492.2 不再细调，更准的横向位置由外参标定给出。
- 内侧墙间距接近设计值，也说明两个盒子都推到了止挡。没推到止挡时盒子偏向外侧，内侧墙间距会明显变大。
- 内侧墙只记录了一个读数。前后、上下各处是否一致（即两盒是否平行）待补充。

## 6. 误差来源与待核查

| 项目 | 影响 | 处理建议 |
|---|---|---|
| 左右横向间距由卷尺测量确定 | 三组测量反推的中心面间距为 492.2 ~ 493.0；每个盒子的横向位置 y 约 ±0.5 mm | 已复核，见第 3.3 节；更准的值由外参标定给出 |
| 左右铁片前后错位、高度差、不平行 | 左右盒之间的 x、z 和角度 | 未测，本文按 0 处理；可按第 7 节在前后、上下分别量盒间距估计 |
| 支架长圆孔调节量 | 盒子相对铁片：前后 ±2.5 mm，上下 ±0.75 mm | 装好后实测盒子位置，或让螺栓居中 |
| 夹缝与铁片间隙 | 夹缝 3.2、铁片约 3：横向 ±0.1 mm | 可忽略 |
| 燕尾导轨间隙 | 盒子相对支架前后约 ±0.3 mm；左右由止挡顶住 | 装盒时推到止挡 |
| 打印件尺寸误差 | 一般在零点几毫米量级 | 实测打印件 |
| 传感器在盒内的位置 | 摄像头和双孔传感器由对称挡板居中；雷达由托板、侧挡板和前面板定位 | 实物装好后核对 |
| 传感器数据原点与轴向 | 雷达测量原点、相机光心位置、IMU 测量中心和轴向，都不能从 CAD 外形得到 | 查 XT-M60 / H30 手册，做内参和外参标定 |
| IMU 位置 | 只在滑盖完全关闭时有效。v2 间隙：前后 0 ~ 0.2、左右 ±0.25、上下 0.2；v1 孔隙约 ±0.25 | 装好后实测；v2 需要消除间隙时可加薄垫 |
| M 系到车体坐标 | 本文不包含 | 另行实测 |

## 7. 装好后的快速核对

用卷尺或卡尺在实物上测，与设计值比较。设计值按第 3.1 节的 492.2 计算。偏差明显时，说明安装链路（铁片 → 支架 → 盒体 → 传感器）有问题，或横向基准需要重新推导。

| 测量项 | 设计值 | 实测 | 说明 |
|---|---:|---:|---|
| 两 U 型夹板（座椅侧）朝座椅面间距 | 479.0 mm | 479 | 已用于推导横向基准，不再作为独立核对 |
| 两 U 型夹板（座椅侧）贴铁片面间距 | 489.0 mm | 489 | 同上 |
| 两盒内侧墙外表面间距 | 393.2 mm | 394 | +0.8，在卷尺误差内；前后、上下是否一致待补充 |
| 两盒外侧墙外表面间距 | 601.2 mm | 待测 | — |
| 左右雷达窗中心距 | 435.7 mm | 436 | +0.3，在卷尺误差内 |
| 左右前摄像头窗中心距 | 541.2 mm | 待测 | 可量两窗同侧边缘之间的距离 |
| 两盒前面板外表面前后差 | 0 mm | 待测 | — |
| 盒底到螺栓孔中心的高度 | 51.5 mm | 待测 | — |

判读：

- 盒间距与设计值相差超过约 1.5 mm：先确认两个盒子都推到了止挡；仍有偏差，就以盒间距为准重新推导横向基准，并更新本文。
- 同一间距在两处测量相差 Δ、两处相隔 L：两盒在对应方向上的转角之和约为 Δ / L（弧度）。例如前后两处相隔约 100 mm、相差 1 mm，约为 0.6°。前后不同对应绕 z 转，上下不同对应绕 x 转。
- 量 U 型夹板时避开前后两端的加强筋。

模型改动后（如移动 IMU 托框、调整传感器挡板），或横向基准复核结果变化后，需要重新计算本文数值。
